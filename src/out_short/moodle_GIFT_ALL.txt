::X-01:: Password hashes\: Linux vs Windows? {}
// MODEL ANSWER: Linux: /etc/shadow. Windows: NTLM in the SAM, and ntds.dit for the domain.

::X-02:: Identifying users\: Linux vs Windows? {}
// MODEL ANSWER: Linux: UID numbers (0 = root). Windows: SIDs (RID 500 = Administrator).

::X-03:: Permissions\: Linux vs Windows? {}
// MODEL ANSWER: Linux: rwx for user/group/world, plus SUID/SGID/sticky and ACLs. Windows: a security descriptor - owner, group, DACL, SACL, flags.

::X-04:: Getting elevated\: Linux vs Windows? {}
// MODEL ANSWER: Linux: sudo, su, runuser, Polkit for the GUI. Windows: UAC elevating your token, or runas.

::X-05:: Extra lockdown layer\: Linux vs Windows? {}
// MODEL ANSWER: Linux: SELinux or AppArmor. Windows: integrity levels, which drive UAC.

::X-06:: Background programs\: Linux vs Windows? {}
// MODEL ANSWER: Linux: systemd units. Windows: services under the Service Control Manager. Both are used for persistence.

::X-07:: Login records\: Linux vs Windows? {}
// MODEL ANSWER: Linux: utmp, lastlog, systemd. Windows: Security event log (4624), query user, psloggedon - all with limits.

::X-08:: Hiding history\: Linux vs Windows? {}
// MODEL ANSWER: Linux: unset HISTFILE, delete ~/.bash_history. Windows: cmd history dies with the session; PowerShell's PSReadLine file can be deleted, and Base64 hides the command's content.

::X-09:: Links\: Linux vs Windows? {}
// MODEL ANSWER: Linux: hard links and symlinks. Windows: shortcuts, hard links (files), junctions (folders), symlinks (admin only).
